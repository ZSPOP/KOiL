# KOiL 油价数据库机制说明

> 记录 KOiL 油价数据库的完整逻辑机制，防止后续迭代遗忘。
> 版本基线：v1.4.184（2026-10-26）。任何改动请同步更新本文档与 CHANGELOG.md。

---

## 1. 数据模型

表 `koil_prices`，主键 `(province, grade, effectiveDate)`：

| 字段 | 说明 |
|---|---|
| province | 省份（31 个省/直辖市，`OilPriceDbSyncer.PROVINCES`） |
| grade | 油号：92号汽油 / 95号汽油 / 98号汽油 / 0号柴油 |
| effectiveDate | **生效日 = 发改委窗口日 + 1 天**（窗口「24 时」生效 → 次日 0 点） |
| price | 元/L；**搁浅窗口 = 维持价（上一窗口价）** |
| source | 来源 URL（abapi / 窗口搁浅·维持） |
| isVerified | 官方已核验标记 |
| isStranded | **v1.4.181 新增**：0=调价窗口，1=搁浅窗口（窗口日到了但价格未变） |

> 历史：v1.4.159 表名 fuel_prices → koil_prices；v1.4.181 加 isStranded 列（DB v2→v3）。

## 2. 锚点 5 级链（v1.4.184 起顺序）

锚点 = 一个已知窗口日。**①②③④ 只提供单个锚点日期，⑤ 负责推算当年全年窗口日历**。

| 级 | 来源 | 取什么 | 备注 |
|---|---|---|---|
| ① | **xxapi**（v2.xxapi.cn/api/oilPrice） | 最近窗口生效日 − 1 天 | **v1.4.184 升为①**（apizero 近期不稳定） |
| ② | **ruseo**（api.ruseo.cn/api/oilprice） | 最近窗口生效日 − 1 天 | 与 ① 同源互备 |
| ③ | **apizero 预测专接口**（fetchForecast） | 结构化 `nextAdjustDate`（下个窗口日） | **v1.4.184 由①降为③** |
| ④ | **abapi 全年曲线**（abapiAnchor） | 最近调价日（**生效日 − 3 天**） | 实测 18/18 与发改委公告吻合 |
| ⑤ | **本地推算**（calculateAdjustDates） | 从锚点推算当年全年窗口日列表 | 纯本地算法，断网可用 |

**配套缓存**（不算级，但关键）：
- 内存缓存 + 持久化缓存（`settings.priceDbAdjustDates`）：App 重启后复用上次已推算的窗口日历；
- 缓存命中即使 ①-④ 全失败也不空降级（杜绝假生效日）；缓存命中时照常执行假日期清理。

## 3. 窗口日历推算规则（⑤）

`calculateAdjustDates(anchor, holidaySet, workdaySet)`：

- 锚点按**「10 个工作日 ≈ 14 自然日 + 节假日顺延」**：
  - **向后顺推**：从锚点（若在本年）每 +14 天（遇节假日再顺延）至当年末；
  - **向前倒推**：从锚点每 −14 天（遇节假日再顺延）回溯至当年首调。
- 节假日数据来自 **chinese-days**（放假日 + 调休补班日），拉取「去年/今年/明年」三年；某年缺失则按纯工作日推。
- 结果升序、含历史与未来窗口，写入 `settings.priceDbAdjustDates`（逗号分隔持久化）。

## 4. 灌库流程（seedProvince）

拉单省当年曲线（abapi range=year，实测返回约 13 个月数据，含上一年）并写入：

1. **幂等**：按 `省|油号|生效日` 键跳过已存在（重灌/补灌不重复插）；
2. **变化点插入**：只存「价格有变化」的点（调价日）；生效日 = `窗口日 + 1`（归并：abapi 滞后日期 → 最近窗口日）；
3. **补搁浅（v1.4.181）**：对每个**已过窗口**（窗口日 ≤ 今天），若「窗口日+1」无生效记录 → 插入搁浅记录（`isStranded=true`）：
   - **维持价** = abapi 曲线中 **≤ 窗口日的最后一个价格点**（不设当年下界）；
   - **首窗口搁浅**（如 1-06）：abapi 当年曲线 1-06 前无点 → 回退到**上一年最后一个调价点（上年末价）**；
   - **同价假记录清理（v1.4.182）**：灌库前删除「isStranded=false 且价格与上一条相同」的历史遗留假点（真实调价必然变价；早期版本「窗口归档」遗留的假记录如 10-16 会挡住搁浅幂等）。

**触发**：`seedRemainingProvinces`（立即更新/定时更新尾部 + 启动兜底）：
- 条件：各省已覆盖窗口数 < **已过窗口数**（含搁浅，threshold = `adjustDates.count { it <= today }`）→ 补灌；
- `seedLock` 防并发（CAS）。

## 5. 一次性灌库 + 持续增量模型（v1.4.183）

- **2026 起点一次灌库**（31×4×已过窗口全量，含搁浅）→ 之后**永不重灌**；
- 新窗口日到了 → **增量加记录**：调价（调价检测插入）或搁浅（补搁浅插入）；
- **跨年（2027）不清库**：`purge` 只清「当年 1-1~12-31 内的假日期」，**往年日期一律保留**，历史持续累加。

---

## 6. 假日期清理（purge）

`purgeIllegalEffectiveDates(dates)`：

- 白名单 = 当年窗口日历每个窗口日 + 1 天；
- **只删**：生效日在「当年 1-1 ~ 12-31」**且**不在白名单的记录（如降级灌入的 09-27）；
- **不碰往年**（v1.4.183 起）。
- 调用点：设置页打开/刷新状态时（`purgeIllegalEffectiveDatesIfReady`）+ 窗口日历推算/缓存命中时。

## 7. 统计口径

| 展示项 | 口径 |
|---|---|
| **調價 N**（设置页数据库卡） | 窗口日历中**今年已发生窗口日数（含搁浅）** = `adjustDates.count { it <= today }` |
| **記錄 N** | 库内全量记录（变化点 + 搁浅窗口，`COUNT(*)`） |
| **上調/下調次数**（记录页汇总） | 库内 `isStranded=false` 记录中 diff>0.001 / diff<-0.001 的条数（首条有前值时计入，如 1-06 入库后 01-21 计上调） |
| **擱淺次数**（记录页汇总） | `records.count { it.isStranded }`（v1.4.181 起直读库，不再差集） |
| **淨漲跌 / 累計上調 / 下調金額** | 仅统计非搁浅调价的 diff 累加 |
| **缺口提示** | 各省覆盖窗口数 < (有记录窗口数 − 2) → 红条警示（提示补灌） |

> 口径修正史：v1.4.180 曾用「窗口 − 上調 − 下調」差集算搁浅（首条基準價导致多 1，20−17=3 vs 真实 2）→ v1.4.181 改为直读 `isStranded`。

## 8. 记录页展示口径（OilPriceDetailScreen / ViewModel）

- 数据源：`observeByProvinceGrade` 查库（升序），**直接包含搁浅记录**（无展示层补全）；
- **日期显示**：调价记录 = 生效日（如 10-16）；**搁浅记录 = 窗口日（生效日 − 1 天，如 10-15）**（与数据库卡「調整日」一致）；
- **搁浅行**：灰色日期/价格/标签 + 灰色「擱淺」chip + 尾部「維持 09-25 價格」；
- **首窗口搁浅**（keptFrom=null）：尾部显示「維持 上年價格」；
- **走势图**：价格序列含搁浅（同价 → 水平线），台阶正确；
- **省份切换**：横向滑动 chips + 左右箭头（v1.4.180，可点可滑，边界变灰）。

## 9. 调价检测 / 更新机制

- `performPriceCheck`：主源 ruseo + 次源 xxapi 双源当日价核验（同源互备）；apizero 预测专接口并行（失败不影响主流程）；
- **窗口日**：预测专接口（nextAdjustDate）→ 聚合接口文本 → 推算日历下个未来窗口；
- **窗口滚动**：旧 next 已过 → 升级为 prev；过期预告直接作为 prev 存档（避免首次同步即永久缺 prev）；
- **数据源日期滞后**：跳过本次核验（不误报）；
- **定时更新**：约 8 小时一次；通知开关控制推送（未授权静默）；
- **启动兜底**：全国补灌 + 假日期清理。

## 11. 已知边界与依赖

| 项 | 说明 |
|---|---|
| **数据源非官方** | abapi/ruseo/xxapi/apizero 均为第三方，价格与日期可能有 1-3 天滞后或细微偏差——**库逻辑已闭环，剩余不确定性来自数据源** |
| 锚点极端退化 | ①-④ 全失败且无缓存 → 空降级（seedProvince 用 abapi 原日期）；⑤ 本地推算断网可用，锚点缺失概率极低 |
| abapi 只给当年数据 | 首窗口搁浅维持价取不到 → 该条跳过（保持现状，不给错价） |
| 各省缺窗口 | abapi 偶发缺某省某窗口 → 缺口红条提示补灌 |
| 全新安装断网 | 只有预置快照（如有）或空库，联网后立即更新自动补灌 |
| 跨年分年回看 | 库内保留历史（v1.4.183 起），记录页尚未分年维度（2027 前可选做） |
